# Token-Saver 边界条件

## 适用场景

| 条件 | 预期表现 |
|------|---------|
| 中文电商短视频（30-120s） | 已验证，评测类 4/4 全胜 |
| 有音轨、有口播内容 | 核心依赖 ASR 文本信号 |
| 预算 B ≥ 12 | B 太低时均匀采样有结构性优势 |
| 品类有明显的信息密度差异（产品介绍 vs 闲聊） | Surprisal 信号强 |

## 不适用 / 需降级的场景

### 无音轨视频

Token-Saver 完全依赖 ASR 文本。无音轨或纯音乐视频无法评分。

**处理**：检测无音轨 → 回退到 Uniform 采样或场景检测。

### 口播视频（连续说话、画面固定）

口播视频中 50%+ 秒是"关键帧"，任何自适应方法无法击败均匀采样。

**处理**：视频类型预判（停顿比 < 0.15）→ 回退 Uniform。

### 非中文视频

Surprisal 和 trigram backoff 语言无关，理论上可迁移。但：
- 中文分词（jieba）需替换为目标语言的分词器
- 信息点正则和填充词词典需重新构建
- 权重未经校准

**处理**：Surprisal 可保留使用；其他维度需要语言适配 + 重新校准。预计 Surprisal 仍为最强信号。

### 极短视频（< 15s）

B=10 的预算可能超过或接近视频秒数。

**处理**：当 `budget ≥ total_seconds` 时直接返回所有秒，不做选择。

### 长视频（> 10min）

5 秒窗口 + 逐秒评分在 10min+ 视频上计算量线性增长。窗口大小可能需要调整。

**处理**：未测试。学术界的 FOCUS/DynaTok 等方法在长视频上有更多验证。

## 已知局限

| 局限 | 严重程度 | 说明 |
|------|---------|------|
| 样本量 8 条 | 高 | 无统计显著性检验，结论为探索性 |
| 仅中文 | 中 | 所有校准在中文电商视频上完成 |
| VLM 评估噪声 | 中 | 品牌幻觉率 ~60%，L2 评估区分度受限 |
| 标注主观性 | 中 | 人工关键帧标注由研究者本人完成，存在标注者偏差 |
| 单一品类 | 低 | 校准数据为清洁消毒品类，跨品类泛化未验证 |

## 需要重新校准的情况

| 变更 | 影响 | 需要重新校准的内容 |
|------|------|------------------|
| 更换 ASR 引擎 | 词级时间戳分布变化 → 评分分布漂移 | 五维权重、窗口大小 |
| 更换分词器 | TTR 和熵值变化 | TTR 和熵的权重 |
| 新视频品类 | 信息密度模式不同 | 视频类型预判阈值、权重可能需微调 |
| 新语言 | 所有语言相关信号变化 | 全部参数 |
| 更换 MLLM 模型 | Token-Saver 本身不依赖 MLLM | 不需要重新校准（模型无关设计） |

## 理论下限

口播视频 + 极端预算（B ≤ 5）时，Token-Saver 退化为带噪声的均匀采样。此时：
- 如果视频确实信息均匀分布 → 与 Uniform 持平
- 如果评分噪声导致帧聚集 → 比 Uniform 更差

这是内容结构决定的天花板，非算法可突破。
