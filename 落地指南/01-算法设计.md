# Token-Saver 算法设计

## 一句话

在 MLLM 推理前，用 ASR 文本的信息密度估计选出 K 个关键帧。免训练、纯 CPU、模型无关。

## 为什么文本信号就够了

电商短视频（30-120s）中，画面切换不等于信息密度变化。口播视频 50%+ 帧是同一张脸，评测视频的产品特写只在少数时刻出现。但**语音一直在传递信息**——品牌名、价格、卖点、对比——这些词的密度在时间轴上的分布天然标记了关键片段。

实验证实：纯文本评分与全模态（文本+视觉+耦合检测）的 F1 差距仅 0.008。文本信号是性价比最高的信息密度代理。

## 五维文本密度评分

对每秒视频，在 5 秒滑动窗口内计算 5 个维度的加权组合：

```
I(t) = 0.40 × S_norm(t) + 0.31 × I_norm(t) + 0.12 × H_norm(t) + 0.10 × R_norm(t) + 0.07 × T_norm(t)
```

### Surprisal（权重 0.40）— 主导信号

用 trigram backoff 语言模型估计每个词在其上下文中的条件概率，取负对数：

```
S(w_i) = −log₂ P(w_i | w_{i−2}, w_{i−1})
```

Laplace 平滑 α=0.1。窗口中所有词的 surprisal 取均值。

**为什么它最强**：`苏泊尔`、`氨基酸`、`不粘涂层`、`¥299` 在整个语料中概率极低。当它们密集出现在 3-5 秒窗口时，surprisal 急剧上升——这正是产品介绍的时刻。Surprisal 是唯一不需要电商领域知识的信号。

### 信息点密度（权重 0.31）

正则匹配电商实体，计算窗口中实体词占总词数的比例：

```
I_density(t) = count(实体词 in window_t) / len(window_t)
```

实体正则覆盖：价格（`¥\d+`、`\d+元`）、折扣（`\d+折`）、量词（`\d+[份件个瓶盒袋箱套]`）、规格（`\d+g/克/ml/毫升`）、百分比（`\d+%`）、排名（`第.+名`）。

### 信息熵（权重 0.12）

窗口内词频分布的 Shannon entropy，用 log₂(|unique_words|) 归一化：

```
H(t) = −Σ p(w) × log₂ p(w) / log₂(|V_t|)
```

高熵 → 词汇多样 → 可能包含更多信息类别。

### 冗余度反向（权重 0.10）

```
R(t) = 1 − (填充词比例 + 重复率) / 2
```

填充词：`就是、然后、那个、这个、嗯、啊、呃、吧、嘛、呢、的话、就是说、其实...`

重复率：窗口中出现 ≥2 次的词占总词数的比例。

低冗余 = 高信息密度。

### TTR（权重 0.07）

滑动窗口内的 type-token ratio：

```
TTR(t) = |unique_words in window| / |total_words in window|
```

中文分词噪声（jieba）导致 TTR 区分度低，权重最低。

## 评分的时间分辨率：窗口→逐秒展开

五维评分在 5 秒窗口、1 秒步长上计算，每个窗口得到一个 composite score，落在窗口中心秒：

```
窗口 1: [0s, 5s) → score 给 center = 2s
窗口 2: [1s, 6s) → score 给 center = 3s
窗口 3: [2s, 7s) → score 给 center = 4s
...
```

非中心秒用最近邻插值回填：

```
score(t) = score(center_k)  where k = argmin |center_i − t|
```

这一步骤的时间精度取决于步长——1 秒步长意味着相邻秒的评分来自于同一个窗口中心，在 1 秒粒度上评分是分段常数的。对于帧选择（最小间距 2-3 秒）来说，这个精度足够了。如果需要更高时间精度，可以减小步长到 0.5 秒，代价是计算量翻倍。

## 帧选择：贪心 Top-K + min-gap

```
1. I(0) 和 I(T−1) 提升至 max(I)×1.1（首尾帧强制包含）
2. 按 I(t) 降序排列所有秒
3. 贪心取 Top-K，跳过与已选帧间距 < min_gap 的候选
   min_gap = max(1, total_seconds / (budget × 2))
```

**为什么不用 MMR**：消融实验表明 MMR 多样性惩罚将一些中等重要性但视觉独特的关键帧（如产品特写切换）也作为"冗余"惩罚掉了，净效果 −5% F1。重要性评分本身的分散度已足够。

## 视频类型预判

在评分之前做轻量级二分类：

```
停顿比 = 无词窗口(>1.5s)的总秒数 / 视频总秒数

停顿比 < 0.15 → 口播 → 跳过评分，直接用均匀采样
停顿比 ≥ 0.15 → 评测 → 走完整 Token-Saver 评分
```

口播视频中 50%+ 的秒都是"关键帧"，任何自适应方法无法击败均匀采样。不如直接回退，省掉评分计算。
