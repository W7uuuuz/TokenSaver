# Token-Saver 实验结论

> 6 个实验 × 8 条视频 × 3 个 MLLM 模型
>
> **口径说明**：本文档为研究阶段旧简化版数据（B=10 F1 0.516 等）。生产口径最新结果见 `WHITEPAPER_DRAFT.md` §6.2-6.3（recall 0.941 / F1 0.751 / L2 5-3-0）；旧版部分领先来自选帧聚类 bug（见 §7.2）。

## 核心结果

| 评估层 | 方法 | Token-Saver 表现 | 解读 |
|--------|------|-----------------|------|
| L1 F1（帧命中率 vs 人工标注）| B=10 | TS 0.516 vs **Uniform 0.556** | Uniform 略优 |
| L1 F1 | B=20 | **TS 0.802** vs Uniform 0.795 | TS 反超 |
| L2 MLLM（内容理解盲评）| B=10 | **TS 6-2-0** 胜 Uniform | TS 显著优于 |

**关键洞察**：L1 和 L2 结论矛盾。人工标注者倾向选择"每一秒的关键帧"（覆盖 35-50% 秒数），B=10 的极端压缩比下自适应方法 F1 天然吃亏。但 MLLM 只需要信息密度最高的几帧就能正确回答——L2 才是真实目标的评估。

## 消融实验（B=10, L1 F1）

| 移除模块 | F1 变化 | 结论 |
|----------|---------|------|
| 耦合增强 (1.5×) | **+7.3%** | 耦合增强在拖后腿 |
| MMR 多样性惩罚 | **+4.7%** | MMR 在拖后腿 |
| 视觉特征 (HSV+光流) | +3.1% | 边际贡献有限 |
| 场景检测增强 | +0.8% | 无显著影响 |
| 自适应 λ | 0.0% | 无影响 |

**简化后的有效 pipeline**：`ASR → 5维评分 → Top-K + min-gap`。代码量从 ~2500 行降到 ~160 行，无性能损失。

## 为什么 Surprisal 是主导信号

5 个维度中 Surprisal 权重 0.40，所有 Top-10 候选权重组合中 Surprisal ≥ 0.30。

**原理**：电商视频中真正的信息——品牌名、产品宣称、价格数字、规格参数——在整个语言模型中概率极低。当它们密集出现时，trigram backoff 模型会给这些词分配高 surprisal 值。这是唯一不需要电商词典、正则、填充词表的信号。

| 信号 | 需要领域知识 | 跨领域可用性 |
|------|------------|------------|
| **Surprisal** | 否 | 教育、汽车、房产等任意领域 |
| 信息点密度 | 是（正则词典） | 需要更新实体模式 |
| 冗余度 | 是（填充词词典） | 需要更新填充词表 |
| 熵 | 否 | 但区分度低 |
| TTR | 否 | 中文分词噪声大 |

**跨领域迁移建议**：Surprisal 不加修改直接使用；其他四个维度需更新词典/正则。权重可能需要重新校准，但 Surprisal 的主导地位预计保持。

## L1 F1 vs L2 MLLM 指标张力

| 假说 | 解释 |
|------|------|
| **假说 A**：人工标注有"均匀分布"偏差 | 标注者选了 15-43 个关键帧覆盖 35-50% 秒数，极端压缩下 F1 对自适应方法不公平 |
| **假说 B**：MLLM 评估有 VLM 噪声 | 品牌幻觉率 ~60%，LLM-as-judge 评分受幻觉输出影响 |
| **假说 C**：L1 和 L2 测量的是不同东西 | F1 测量"标注重叠"，L2 测量"理解质量"，两者目标不同 |

**实践建议**：
- L1 F1 用于快速迭代/调试，不作为最终结论依据
- 关键结论必须用 L2 MLLM 验证
- 如果必须只用 L1，用 NDCG@K（衡量排序质量）而非 F1（衡量二分类命中率）

## 评测 vs 口播：内容类型决定天花板

| 视频类型 | Token-Saver 表现 | 原因 |
|----------|-----------------|------|
| **评测类** | 4/4 全胜 Uniform | 产品特写集中在少数关键时刻 |
| **口播类** | 2 赢 1 输 1 分散 | 人脸固定，信息均匀分布 |
| **零耦合口播** | 与 Uniform 相当（评分退化） | 画面静态 + 文本均匀 |

**结论**：在管道中预判视频类型，口播直接用 Uniform（更简单，效果不差）。

## VLM 幻觉：评估的噪声天花板

- 品牌命名错误率：~60%（TS 和 Uniform 均频繁出错）
- 品类识别错误率：~25%（Uniform 更易错）
- 完全无法识别率：~20%（集中在口播视频）

**启示**：不要信任 VLM 的品牌识别。品牌/价格信息应从 ASR 文本直接提取，而非依赖 VLM 看图。

## B=20 是拐点

| 预算 | TS F1 | Uniform F1 | 差值 |
|------|-------|-----------|------|
| B=10 | 0.516 | 0.556 | −0.040 |
| B=20 | 0.802 | 0.795 | +0.007 |

B=10（~6:1 压缩）时帧数不足以覆盖关键帧分布。B=20（~3:1 压缩）时自适应信号的优势开始体现。**推荐最小预算为 B=12-15**。
