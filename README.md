# TokenSaver

**面向电商短视频的确定性免训练帧选择——在 MLLM 推理前，基于 ASR 文本的信息密度将视频压缩至固定帧预算，以降低 token 成本。**

TokenSaver 是一个纯 CPU、免训练、模型无关的预处理模块：输入视频，输出 B 个关键帧索引，可接入任意多模态大模型（MLLM）。本项目不进行"更像关键帧"的视觉分析，而是在固定预算下**将帧从低信息密度区间向高信息密度区间重新分配**。

---

## 核心成果

**降本为核心目标，选帧本身零成本。** 以 MLLM 全帧识别为基准（21 条人工标注全集），确定性降帧在省 **39%**（生产默认档，19 任务实证）到省 **64%**（0.5 档，仅使用全帧 **36%** 的 image token）的整个压缩区间内，理解保持率均 **≥1.0**，即降帧不损失理解；选帧过程本身 **¥0**（纯 CPU 确定性计算，无任何 LLM 调用）。

**TokenSaver 采用「均匀骨架 + 算法增量」的结构。** 均匀骨架（口播每 4s、评测每 2s 一帧）本身即为均匀采样，保证全片覆盖与首末帧；算法增量在此基础上将预算向文本高密度区重新分配。评分平坦时，算法退化为纯均匀采样。

**降本结果**(主实验,以全帧为基准):

| 口径 | 方法 | 档位 | image/全帧 | 理解保持率 |
|------|------|------|-----------|-----------|
| 内容+ASR | TokenSaver | 0.5 | 36% | 1.091 |
| 内容+ASR | 纯均匀采样 | 0.5 | 36% | 1.086 |
| 内容+ASR | 转场优先(TF) | 0.5 | 35% | 1.101 |
| 纯视觉 | TokenSaver | 0.5 | 36% | 1.045 |
| 纯视觉 | 纯均匀采样 | 0.5 | 36% | 1.049 |
| 纯视觉 | 转场优先(TF) | 0.5 | 35% | 1.065 |

- 全档位(0.5/0.7/0.9)保持率均 ≥1.0,压缩没有"质量拐点"。
- 三方法保持率接近,印证「均匀骨架本身已保证覆盖」;选帧方法的差异在 L2 被帧数(token 量)主导。

**关于 L1 帧匹配**：单独评估 L1 时，TokenSaver 的 recall 为 **0.941**，覆盖 94% 的人工关键帧。F1 略低于纯均匀采样，原因在于「骨架 + 增量」架构下，均匀骨架为保持叙事连贯而设置的帧，在容差口径下被计为"未命中"。

**相同帧数下的表现**（生产口径，带 ASR）：在相同帧数下，TokenSaver 将增量帧落在文本高密度区，完整性与准确性优于纯均匀采样（平均分 **8.9 vs 8.4**）；该增益依赖 ASR 提供的文本内容地基。

## 为什么需要 TokenSaver

MLLM 处理视频时,每帧约消耗 2,100 个视觉 token:

| 输入 | 视觉 token |
|------|-----------|
| 单帧 | ~2,100 |
| 60s @ 1fps | ~126,000 |
| 60s @ 0.5fps | ~63,000 |

电商场景的典型形态为"短时长 × 海量条数"，日均千万级的上架量使全帧输入带来的线性成本难以承受。而视频帧存在大量时序冗余——真正承载信息（价格、卖点、品牌）的往往只有少数时刻。

**关键观察**：画面切换并不等同于信息密度变化，而**语音始终在传递信息**——品牌名、价格、卖点、成分。因此，ASR 转写文本是画面之外成本最低的信息密度时间代理。

## 方案一览

```
video.mp4
  → [ASR 转写]            # 复用已有 ASR 子系统,零新增成本
  → [5维文本密度评分]      # Surprisal 主导,窗口 5s / 步长 1s
  → [自适应帧选择]         # 均匀基线 + 评分关键帧增量 + 覆盖兜底
  → B 个帧索引            # 输出秒级索引,接入任意 MLLM
```

设计原则:

- **免训练**：纯确定性计算，无需 GPU、标注或微调。
- **零视觉编码**：不为"选帧"额外运行任何视觉模型，避免引入二次幻觉。
- **模型无关**：视频 → 帧索引列表 → 可接入任意 MLLM。
- **可审计**：每个帧选择决策均可追溯到具体的密度评分与策略分区。

result = compress_video("video.mp4", budget=10)
print(result["frame_indices"])       # → [0, 3, 7, 15, 22, 30, 35, 40, 45, 50]

## 核心原理:五维文本信息密度评分

对每秒视频,在 5 秒滑动窗口(步长 1s)内计算 5 个维度的加权组合,min-max 归一化后加权求和:

```
I(t) = 0.40×Surprisal + 0.31×信息点密度 + 0.12×信息熵 + 0.10×反冗余 + 0.07×TTR
```

| 维度 | 权重 | 方法 | 信号含义 |
|------|------|------|----------|
| **Surprisal 惊奇度** | 0.40 | Trigram backoff LM,Laplace α=0.1 | 低概率词爆发 → 领域特定信息 |
| 信息点密度 | 0.31 | 电商实体正则命中 / 窗口 token 数 | 价格、规格等产品信息 |
| 信息熵 | 0.12 | Shannon entropy,log₂(\|V\|) 归一化 | 词分布均匀度 |
| 反冗余 | 0.10 | 1 − (填充词比 + 重复率)/2 | 低冗余 → 高信息密度 |
| TTR | 0.07 | 窗口 type-token ratio | 词汇多样性 |

**Surprisal 是主导信号**。`苏泊尔`、`氨基酸`、`¥299` 等词在整个语料中概率极低，当它们在 3-5s 窗口密集出现时，surprisal 急剧上升——这正是产品介绍的典型时刻。该信号不依赖电商领域知识，可直接跨领域迁移。

权重通过 500 组 Dirichlet 采样 + 8 条人工标注 NDCG@K 网格搜索校准。

## 帧选择:均匀基线 + 算法增量

生产算法的核心是**两层覆盖**(详见 `落地指南/06-自适应帧选择.md`):

1. **评分分布自检**:计算 composite 评分的变异系数 CV = std/mean,按区间决定策略——评分平坦(CV < 0.15)直接退化为均匀采样,信息峰值显著(CV > 0.22)走"均匀基线 + 评分关键帧",灰色地带混合。
2. **均匀基线**:覆盖率驱动,保证全片视觉覆盖与叙事连贯。
3. **关键帧增量**:按评分降序选帧 + min-gap 防聚类,叠加到基线上。
4. **覆盖兜底**:任意相邻帧间距 ≤ 4s,首尾帧必选。

评分完全退化（如无音轨、信息分布均匀）时，TokenSaver 会回退为均匀采样，效果不会更差。

## 局限

| 局限 | 说明 |
|------|------|
| 样本量 21 条 | 主实验已扩至人工标注全集,但单领域(电商短视频)无跨域验证 |
| 仅中文 | jieba 分词 + 电商词典均中文专用 |
| 口播天花板 | 50% 秒都是关键帧时,任何自适应方法无法击败均匀采样 |
| 无音轨 | 完全无法评分 → 回退均匀采样 |
| 长视频(>10min) | 逐秒评分计算量线性增长,未验证 |
